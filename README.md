# To-do list
список задач для себя с добавлением, маркировкой, редактированием, и удалением.
## Функции
1. addTodo - создает задачи.
2. updateTodo - обновляет задачи.
3. editTodo - редактирует задачи.
4. toggleTask - маркирует задачи (выполненно/не выполненно).
5. deleteTask - удаляет задачи.
## На чем работает проэкт?
- работает на React библиотека JavaScript-а
## Как запустить проэкт?
1. зайдите в консоль
2. зайдите в рабочую папку (папка где хранится этот проект) введя в консоль команду - "cd (название этого проэкта)".
3. далее после того как зашли в проэкт запустите его написав в консоль - "npm start"
